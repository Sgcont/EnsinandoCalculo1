# EnsinandoCalculo1

Aplicativo em Python para introdução a Cálculo 1 com:

1. **Página de conteúdo** com os principais tópicos.
2. **Página de questões objetivas** com correção automática (verde para certo, vermelho para errado) e gabarito.

## Como executar

```bash
pip install -r requirements.txt
streamlit run app.py
```
